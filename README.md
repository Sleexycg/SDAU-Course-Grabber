# SDAU Course Grabber

山东农业大学教务系统已选课程查询与抢课命令行工具。项目使用 Python 3.11+，不需要 Node.js、TypeScript 或 Bun。

> 本项目依赖学校教务系统当前的页面、接口和返回格式，不是学校官方程序。请遵守学校规定并控制请求频率；首次真实使用前，建议在开放期使用低风险课程核对选课期次、教学班 ID 和返回结果。

## 功能概览

- 提供交互菜单和命令行直通模式。
- 登录教务系统并维护 Cookie 会话，会话失效时可安全刷新。
- 查询已选课程，按课程类型分组并分别统计课程数和学分。
- 查询成功后自动生成 PNG 课程表，无需安装额外的图片处理库。
- 对中文课程名、教师、时间和地点进行终端表格对齐。
- 保留一门课程的多条上课时间，并与地点逐项对应。
- 严格匹配目标学期的选课期次后提交教学班 ID。
- 并发轮询多个候选课程，并通过中央配额限制成功数与在途请求。
- 使用 PyInstaller 导出空白版或内置配置版单文件 EXE。

当前程序只查询“已选课程结果”，不会搜索全部可选课程，也不提供外部通知或批量账号功能。

## 运行环境

- Windows 10/11。
- Python 3.11 或更高版本。
- 可访问山东农业大学教务系统。
- 有效的教务系统学号和密码。

程序运行只使用 Python 标准库，不再需要 `cryptography`；构建 EXE 还需要 `PyInstaller`。推荐直接使用项目提供的 `setup.ps1` 完成安装。

## 快速开始

在项目根目录打开 PowerShell，执行：

```powershell
.\setup.ps1
```

脚本会：

1. 查找 Python 3.11+。
2. 创建或复用项目内的 `.venv`。
3. 安装项目、运行依赖和 PyInstaller。
4. 验证 Python 环境。

如果 PowerShell 执行策略阻止脚本运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

安装完成后，双击 `start.bat`，或者执行：

```powershell
.\start.bat
```

也可以直接使用虚拟环境：

```powershell
.\.venv\Scripts\python.exe -m main
```

首次运行且尚未配置账号时，程序会引导进入配置界面。

python -m venv .venv

激活虚拟环境后可以直接使用 `course-grabber` 命令：

### 抢课参数

```powershell
.\start.bat grab 2026-2027-1 `
  --course-id 教学班ID1 `
  --course-id 教学班ID2 `
  --course-name 课程名称1 `
  --course-name 课程名称2 `
  --count 1 `
  --poll-ms 800
```

| 参数 | 说明 |
|---|---|
| `term` | 可选，格式为 `YYYY-YYYY-1/2`；省略时按日期判断 |
| `-c, --course-id` | 教学班 ID，可重复使用或传入逗号分隔值 |
| `--course-name` | 与教学班 ID 按位置对应，可重复使用 |
| `--count` | 成功目标数量，默认 `1`，最高为 `7` 且不能超过候选课程数 |
| `--poll-ms` | 轮询间隔，最低 `300` 毫秒 |
| `-y, --yes` | 跳过启动前确认 |

命令行显式传入的课程会覆盖配置中的目标课程。相同教学班 ID 只会启动一个任务。

## 默认学期

查询和抢课使用同一套日期规则：

| 日期范围 | 默认学期 |
|---|---|
| 每年 7 月 20 日至次年 2 月 15 日 | 该学年的第 1 学期 |
| 每年 2 月 16 日至 7 月 19 日 | 上一学年开始的第 2 学期 |

例如：

- `2026-07-20` 至 `2027-02-15` 默认 `2026-2027-1`。
- `2027-02-16` 至 `2027-07-19` 默认 `2026-2027-2`。

交互界面只显示当前选中的学期：

```text
当前学期：2026-2027-1（通过↑/↓键切换,Enter确认）
```

- `↑` / `↓`：切换学期。
- `Enter`：确认。
- `Esc`：恢复进入界面时由日期判断出的默认学期。
- `E`：手动输入学期。

终端不支持方向键读取时，会自动改用 `p` / `n` 和文本输入。

## 配置

执行：

```powershell
.\start.bat config
```

源码模式从当前工作目录读取 `.env.local`、`.env` 和 `courses.json`，因此建议始终在项目根目录运行。EXE 模式使用 EXE 所在目录。配置界面会原子写入文件，避免保存中断留下半份配置，并使用当前 Windows 用户的 DPAPI 保护密码。

| 变量 | 默认值 | 说明 |
|---|---:|---|
| `STUDENT_ID` | 无 | 学号，登录必需 |
| `PASSWORD` | 无 | 密码；通过配置界面保存时使用 Windows DPAPI 加密 |
| `TARGET_COURSE_IDS` | 无 | 教学班 ID，多个值用逗号分隔 |
| `TARGET_COURSE_NAMES` | 无 | 可留空；非空时必须与 ID 数量相同并按位置对应 |
| `POLL_INTERVAL_MS` | `800` | 抢课轮询间隔，范围 `300-3600000` 毫秒 |
| `JW_TIMEOUT_MS` | `12000` | 单次 HTTP 请求超时，范围 `100-300000` 毫秒 |
| `JW_RETRY_COUNT` | `2` | 可安全重放请求的重试次数，范围 `0-20` |
| `JW_USER_AGENT` | 内置浏览器 UA | HTTP User-Agent |

配置菜单直接编辑学号、密码、轮询间隔和目标课程。教务系统地址固定为 `https://jw.sdau.edu.cn`；超时、重试次数与 User-Agent 需要手动编辑配置文件或通过系统环境变量设置。

配置优先级从高到低为：

1. 系统环境变量。
2. `.env.local`。
3. `.env`。
4. EXE 内置配置。
5. 程序默认值。

未知或旧版废弃字段会被忽略，并在下次通过配置界面保存时移除。

当前密码密文格式为 `enc:v2:dpapi:`。程序仍能读取旧版 `enc:v1:` 和更早的无前缀密文；成功解密后，下次通过配置界面保存时会自动迁移到当前格式，无需手工转换。

建议同时配置课程名称。启动抢课前，程序会按课程名称精确匹配已选结果；只配置 ID 时无法通过名称识别已经选中的目标课程。

## 课程列表

`courses.json` 用于交互式课程选择。仓库中的文件只是待替换数据；使用前应填入真实且唯一的教学班 ID：

```json
[
  {
    "id": "教学班ID-1",
    "name": "课程名称1"
  },
  {
    "id": "教学班ID-2",
    "name": "课程名称2"
  }
]
```

注意：

- `id` 必须是提交选课接口使用的教学班 ID，不是普通课程代码 `kch`。
- 程序不会自动把课程代码转换为教学班 ID，也不会搜索全部可选课程。
- 完全相同的重复 ID 会被去重。
- 同一个 ID 对应不同名称会被视为配置错误。
- 文件缺失或无法使用时，程序会警告并允许手动输入课程 ID。

构建 EXE 时，项目根目录存在的 `courses.json` 会被一并打包。EXE 同目录下的外部 `courses.json` 优先于内置副本。

## 查询结果

查询示例：

```powershell
.\start.bat query
.\start.bat query 2026-2027-1
```

查询进度和总计会使用时间戳日志显示；课程按类型分组，并分别计算课程数和学分：

```text
[2026/8/7 21:36:27] [INFO] 正在查询 2026-2027-1 的选课结果...
[2026/8/7 21:36:28] [SUCCESS] 查询成功：共 17 门课程，29.5 学分

  ──────────────── 必修（7门-12.5学分） ────────────────
  操作系统      4.0分  郝霞    周一 1-2节  19#210

  ──────────────── 限选（10门-17.0学分） ────────────────
  软件工程      3.0分  毕燕东  周二 9-10节  S123
                              周四 9-10节  S123
```

显示规则：

- `必修` 和 `必选` 统一归入“必修”分组，`限选` 单独分组，其他类别保持独立。
- 分组标题以横线居中显示“类型（课程数-学分）”。
- 课程名、学分、教师、上课时间和地点使用空格对齐，不显示表头、序号或竖线。
- 只对必修和限选组排序，其他类别保留接口返回顺序。
- 课程按最早一条可识别的上课时间排序。
- 排序先比较星期，再比较起始节次；周末排在周一至周五之后。
- 时间待定的课程排在所属分组最后。
- 同一门课程的多条安排保持接口顺序，并展开为多行。
- 课程名、学分和教师显示在第一条安排所在行。
- 时间和地点始终作为一个安排整体保留；相同地点不会去重。
- 多个时间只有一个地点时，该地点应用到每条时间；数量不齐时缺失侧显示待定。
- 教师、时间或地点缺失时显示“教师待定”“时间待定”或“地点待定”。

### PNG 课程表

查询成功后，程序还会把同一份选课结果自动生成一张 PNG 课程表：

- 源码模式保存到运行命令时的当前目录；EXE 模式保存到 EXE 所在目录。
- 默认文件名为 `课程表-学期.png`，例如 `课程表-2026-2027-1.png`。
- 已有同名文件时不会覆盖，而是依次生成 `课程表-2026-2027-1-2.png`、`课程表-2026-2027-1-3.png`。
- 默认显示周一至周五；查询结果中存在周六或周日的课程时，自动扩展为周一至周日。
- 课程名、教师和地点会在单元格内自动换行，长中文内容不会挤乱其他列。
- 同一节次存在多门课程时会全部保留并分隔显示，不会用后一门覆盖前一门。由于接口中的安排可能属于不同周次，这只表示时间位置重合，仍需结合教务系统核对是否真正冲突。
- 时间为空或格式无法识别的安排不会丢失，而是集中显示在图片底部的“时间待定”区域。

图片通过 Windows 自带的 GDI+ 生成，不引入 Pillow 等额外运行依赖，也不会为 EXE 增加第三方图像库。课程表图片包含个人课程安排，请妥善保管，不要直接公开分享。

## 抢课流程与安全边界

交互模式：

```powershell
.\start.bat
```

直通模式：

```powershell
.\start.bat grab
.\start.bat grab 2026-2027-1 --count 1 --poll-ms 800
```

程序按以下顺序执行：

1. 登录并建立 Cookie 会话。
2. 查询目标学期的已选课程；查询失败时停止。
3. 按课程名称排除已经选中的目标课程。
4. 获取选课期次列表，并要求目标学期唯一匹配。
5. 进入匹配的选课期次。
6. 为每个唯一候选教学班启动一个轮询任务。
7. 使用中央配额保证“已成功/已选数 + 在途或结果未知的提交数”不超过目标数量。
8. 达到目标数量、收到终止结果或用户按下 `Ctrl+C` 后安全停止。
9. 汇总所有任务的最终状态。

关键安全行为：

- 选课期次缺失或匹配到多个期次时直接停止，不会默认取第一项。
- HTTP 客户端只允许访问配置教务系统的同源地址，并拒绝跨源重定向。
- 安全读取请求可按配置重试网络异常、HTTP 429 和 5xx。
- 选课提交属于不可安全重放的请求，不会因网络异常、HTTP 429 或 5xx 自动重放。
- 提交后遇到断线、5xx、跨源跳转或无法确认的响应时，当前配额不会释放；程序会停止全部新提交并要求重新查询。
- 服务器返回“已选”时，该课程计入已满足目标，不会再用这个名额提交其他课程。
- 只有明确的“课程已满”和“尚未开放”结果会按固定间隔继续轮询。
- 时间冲突、选课关闭和明确的业务失败会终止对应任务。
- 会话失效时，“刷新登录→重新进入原期次→唯一一次提交重试”在同一选课锁内完成，不会使用未重进期次的新会话提交。
- 查询、提交和进入期次都会校验明确的成功/失败标志；字段缺失或结构漂移时拒绝继续。
- 轮询没有总时长或最大次数限制，会持续到达标、终态或用户停止。
- `Ctrl+C` 会阻止后续请求；已经发出的 HTTP 请求可能仍会完成。

## 接口概览

当前实现使用以下教务系统端点：

| 方法 | 路径 | 用途 |
|---|---|---|
| `POST` | `/xk/LoginToXk` | 登录 |
| `GET` | `/xkgl/loadXsxkjgList` | 查询已选课程 |
| `GET` | `/jsxsd/xsxk/xklc_list` | 获取选课期次 |
| `GET` | 期次页面返回的进入链接 | 进入目标选课期次 |
| `GET` | `/xsxk/newXsxkzx` | 提交教学班 ID |

已选课程查询的主要参数为：

```text
lx=xkrz
type=list
pageNum=1
pageSize=200
xnxqid=YYYY-YYYY-1/2
```

提交接口使用 `jx0502zbid=教学班ID` 和 `isallsc=1`。这些都是教务系统内部接口，学校升级系统后可能发生变化。

## 导出 EXE

先确保构建环境已经安装：

```powershell
.\setup.ps1
```

### 空白配置版

```powershell
.\.venv\Scripts\python.exe -m main build --blank
```

输出：

```text
dist\course-grabber.exe
```

空白版不内置账号。将 EXE 放到目标目录后，首次运行时自行配置。

### 内置配置版

```powershell
.\.venv\Scripts\python.exe -m main build --with-config
```

配置版要求当前设置中已有学号和密码。文件名自动使用学号，例如：

```text
dist\2024000001.exe
```

学号只能包含字母、数字、下划线、点和连字符。不传 `--blank` 或 `--with-config` 时，程序会询问是否内置当前配置。交互菜单中的“导出 EXE”使用相同流程。

构建行为：

- PyInstaller 内部过程日志始终隐藏，只显示开始、成功或一条简洁错误。
- 临时入口、spec、工作目录和临时内置配置会在构建结束后清理。
- 项目根目录存在 `courses.json` 时会打包进 EXE。
- 项目根目录存在 `favicon.ico` 时会作为 EXE 图标。
- 输出目录固定为当前工作目录下的 `dist`。
- 同名输出文件可能被新构建覆盖。

> 内置配置版 EXE 为了能在其他电脑上直接运行，会包含可提取的完整配置和明文账号密码。不要公开分发、上传网盘或提交到版本库。空白版不包含账号密码。

## 安全说明

- 配置界面使用 Windows DPAPI 的当前用户作用域保护密码，格式以 `enc:v2:dpapi:` 开头。
- 密文通常只能由原电脑上的原 Windows 用户解密；复制 `.env.local` 到其他电脑或用户账户后通常无法使用。
- 旧版 `enc:v1:` 和更早的无前缀密文仅用于兼容读取；成功读取并再次保存后会自动迁移为 `enc:v2:dpapi:`。
- DPAPI 能降低配置文件被直接读取的风险，但以同一 Windows 用户身份运行的程序仍可能解密它，不能替代良好的系统账户与文件权限保护。
- `.env.local`、`.env`、配置版 EXE 和任何账号清单都应视为敏感数据。
- 配置版 EXE 为了跨电脑运行，内置配置中的密码仍是可提取的明文，不受 DPAPI 保护。
- `.gitignore` 已忽略上述配置、虚拟环境、构建目录和 EXE，但仍应在提交前检查文件列表。
- 项目不支持批量账号，仓库中不应出现 `students.txt` 或其他明文账号清单。
- 如果旧版内置配置文件或旧 EXE 曾被公开分享，应删除残留并更换相关账号密码。

## 常见问题

### PowerShell 找不到 Python

安装 Python 3.11+，安装时勾选“Add Python to PATH”，关闭并重新打开 PowerShell，然后再次执行：

```powershell
.\setup.ps1
```

### PowerShell 不允许运行 setup.ps1

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

### 提示未安装 PyInstaller

优先重新执行：

```powershell
.\setup.ps1
```

或在已经创建的虚拟环境中安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[build]"
```

### `.venv` 已损坏或项目移动后无法启动

直接重新运行 `setup.ps1`。脚本会区分版本过低、无法启动和文件不完整的环境；找到可用的系统 Python 3.11+ 后，只会重建项目根目录下的 `.venv`。如果没有可用的系统 Python，脚本会保留原环境并给出明确错误。

### 密码解密失败

对于当前 `enc:v2:dpapi:` 格式，配置可能来自另一台电脑或 Windows 用户、系统凭据发生变化，或者密文已经损坏；旧版密文还可能因机器名变化而失效。运行：

```powershell
.\start.bat config
```

重新输入密码并保存。

### `courses.json` 提示同一 ID 对应多个名称

每个教学班 ID 只能对应一个课程名称。修正或删除冲突项后重新运行配置。

### 找不到或无法唯一匹配选课期次

可能是当前没有开放选课、目标学期选择错误，或教务系统页面已经变化。程序会停止而不是盲目进入某个期次。

### 提示接口结构可能已经改变

程序要求查询与提交接口返回预期的 JSON/HTML 结构。出现此错误时不要继续高频重试，应先核对教务系统是否升级。

## 测试

项目使用标准库 `unittest`：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py" -v
```

测试覆盖学期边界与键盘选择、配置与加密、HTTP 会话、原子刷新/重进期次、严格接口解析、提交结果未知、查询分组排序、多时间地点配对、PNG 课程表布局与命名、并发配额和构建命名。

测试使用本地假数据与 mock，不读取真实 `.env.local`，不会真实登录、提交课程或运行一次完整的 PyInstaller 构建。
