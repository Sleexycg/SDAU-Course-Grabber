# SDAU Course Grabber

山东农业大学教务系统抢课工具。

## 产品功能

- 查询指定学期的已选课程、教师、学分、上课时间和地点。
- 自动识别课程周数；课程总学时和每周节数明确时，可计算出上课周数。
- 将课程安排导出为 PNG 课程表。
- 显示公选课列表、剩余容量和教师信息。
- 按教学班唯一 ID 抢选公选课，并在提交后确认结果。
- 支持多个目标课程和目标数量，适合在选课开放期间使用。


## 使用方式

直接运行启动脚本，在菜单中选择功能：

```powershell
.\start.bat
```

常用操作：

```powershell
.\start.bat query
.\start.bat query 2026-2027-1
.\start.bat grab 2026-2027-1
```

首次使用时填写学号、密码和目标课程。密码输入会直接显示，便于确认输入内容。

导出的 EXE 固定使用按日期推算的当前学期，不提供学期切换选项。

## 目标课程配置

课程使用教学班唯一标识 `jx0404id`。课程名称和教师只用于显示与人工核对。

```json
[
  {
    "id": "20261145141919810",
    "name": "大学西班牙语3",
    "teacher": "测试"
  }
]
```

课程选择界面显示为：

```text
[测试]-大学西班牙语3
```

教师未知时可留空；提交时仍以 `id` 为准。

## 课程表图片

查询成功后会生成 `课程表-学期.png`。图片包含：

- 周一至周日课程安排；有周末课程时自动扩展显示。
- 课程名称、教师、地点和上课节次。
- 已知的开始周和结束周。
- 时间待定或无法解析的课程安排。
- 同一时间段内的多门课程，不会互相覆盖。

## 轮次选择

程序会读取当前学期的所有选课轮次。若同一学期存在多个轮次，会优先进入唯一一个满足以下条件的轮次：

- `xkzt=1`；
- 当前时间处于该轮次的开始和结束时间内。

如果没有唯一开放轮次，程序会停止并提示，不会进入未知轮次。

轮次已经出现在系统中但尚未开放时，程序会自动等待并定期刷新轮次状态；开放后继续进入并启动抢课。

## 注意事项

- `jx0404id` 是教学班 ID；课程代码 `kch`、课程内部 ID `jx02id` 和轮次 ID `jx0502zbid` 都不能替代它。
- 抢课功能会先查询已选课程和实时剩余容量，再提交目标课程。
- 请确认课程名称、教师和教学班 ID 一致，避免选错同名课程。
- 课程表图片和账号信息属于个人数据，请妥善保存。
