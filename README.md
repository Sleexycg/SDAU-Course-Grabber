## 开发模式（CLI）

适合日常开发和调试。

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

```bash
首次运行程序时会自动创建.env.local，且提供编辑功能
```

### 3. 配置课程列表（可选）

编辑 `courses.json`，抢课时可直接从列表中选择课程，无需手动输入 ID：

```json
[
  { "id": "课程ID1", "name": "课程名称1" },
  { "id": "课程ID2", "name": "课程名称2" }
]
```

### 4. 运行

```bash
npm start
```

显示交互式菜单：

```
  1. 查询选课结果
  2. 启动抢课
  3. 设置环境变量
  4. 导出 exe
  0. 退出
```

也可命令行直通：

```bash
npm run query          # 查询选课结果
npm run query 2025-2026-2   # 查询指定学期
npm run grab           # 直接启动抢课
```
也可使用一键启动脚本
```
start.bat
```

## 静态编译为exe

将配置打包进 exe，发给别人直接运行，无需装 Node.js。

**前提：安装 Bun**

```bash
powershell -c "irm bun.sh/install.ps1 | iex"
```

**编译：**

```bash
npm run build:exe
```

输出：`{学号}.exe`（如 `2024114514.exe`），约 94MB。

编译时会自动：
1. 读取 `.env.local`，密码解密为明文
2. 将学号、密码、课程 ID/名称、学期、教务系统地址等写入代码
3. 执行 `bun build --compile` 生成独立 exe

> 如需修改配置，编辑 `.env.local` 后重新编译。

### 使用 exe

exe 无需任何外部文件，双击或命令行运行：

```
  1. 查询选课结果
  2. 启动抢课
  3. 查看信息
  0. 退出
```

与CLI版的主要差异：

| 功能 | CLI版 | 静态编译版 |
|---|---|---|
| 抢课学期 | 交互式 W/S 选择 | **自动锁死**当前学期的下一学期 |
| 课程选择 | 支持 `courses.json` + 手动输入 | **使用编译内置**的课程 |
| 设置环境变量 | ✅ 支持 | ❌ 不显示 |
| 查看信息 | ❌ | ✅ 在线查询学院、班级 |
| 导出 exe | ✅ | ❌ |
| Webhook 通知 | ✅ | ❌ 不支持 |


```env
POLL_INTERVAL_MS=500
MIN_INTERVAL_MS=200
MAX_INTERVAL_MS=3000
```

## 功能说明

### 抢课模式

自动轮询选课接口，根据服务器响应自适应调整请求频率。

- **CLI 模式**：按 W/S 或 ↑/↓ 选择学期，Enter 确认
- **静态编译**：自动锁定为当前学期的下一学期

```
目标学期：2026-2027-1
目标课程：Web开发技术、Python程序设计
轮询间隔: 800ms (范围 300-5000ms)
```

### 查询选课结果

查询已选课程，按课程类型（必修/限选/任选）分组显示。

- 按 **W/S** 或 **↑/↓** 切换学期
- **Enter** 确认查询
- 推送结果到 Webhook【CLI ONLY】

### 查看个人信息（exe ONLY）

登录教务系统，在线获取并显示：

```
╔══════════════════════════════════╗
║            个人信息              ║
╚══════════════════════════════════╝

  学号：       2024114514
  学院：       信息科学与工程学院
  班级：       计算机2401
  目标课程：     
    1. Web开发技术   （D7F7753A...）
    2. Python程序设计（D7F7753A...）
```

## 环境变量参考

| 变量 | 必需 | 说明 |
|---|---|---|
| `STUDENT_ID` | **是** | 学号 |
| `PASSWORD` | **是** | 教务系统密码 |
| `TARGET_COURSE_IDS` | **是** | 要抢的课程 ID（多个逗号分隔） |
| `TARGET_COURSE_NAMES` | 否 | 课程名称，与 IDs 一一对应（多个逗号分隔） |
| `JW_BASE_URL` | 否 | 教务系统地址，默认 `https://jw.sdau.edu.cn` |
| `TERM` | 否 | 学期，格式 `2025-2026-2`，默认自动推断 |
| `POLL_INTERVAL_MS` | 否 | 初始轮询间隔，默认 800ms |
| `MIN_INTERVAL_MS` | 否 | 最小间隔，默认 300ms |
| `MAX_INTERVAL_MS` | 否 | 最大间隔，默认 5000ms |
| `WEBHOOK_URL` | 否 | 推送通知地址（仅开发模式） |
| `WEBHOOK_METHOD` | 否 | GET（默认）或 POST（仅开发模式） |
| `JW_TIMEOUT_MS` | 否 | 请求超时，默认 12000ms |
| `JW_RETRY_COUNT` | 否 | 请求重试次数，默认 2 |

## 自适应轮询策略

| 返回状态 | 行为 |
|---|---|
| 课程已满（`COURSE_FULL`） | 加速（÷1.2），最低 300ms |
| 未到选课时间（`NOT_OPEN_YET`） | 退避（×1.5），最高 5000ms |
| 时间冲突（`TIME_CONFLICT`） | 自动终止任务 |
| 网络超时/错误 | 退避（×2），最高 3000ms |

## 项目结构

```

├── src/
│   ├── index.ts                 # 入口：菜单 + 命令行
│   ├── types.ts                 # 类型定义
│   ├── env-builtin.ts           # 自动生成 — exe 内置配置
│   ├── lib/
│   │   ├── env.ts               # 环境变量读取（支持内置回退）
│   │   ├── errors.ts            # 自定义错误类
│   │   ├── encoding.ts          # 登录加密算法
│   │   ├── crypto.ts            # 密码本地加密（AES-256-GCM）
│   │   ├── http.ts              # HTTP 客户端（Cookie/超时/重试）
│   │   ├── session.ts           # 登录与会话管理
│   │   ├── course-selector.ts   # 选课接口客户端
│   │   ├── grabber.ts           # 自适应抢课引擎

│   │   └── logger.ts            # 日志工具
├── scripts/
│   └── build-exe.js             # exe 构建脚本
├── courses.json                 # 课程列表（可选）
├── .env.local                   # 本地配置（不提交）
├── package.json
└── tsconfig.json
```
